
# 🍔 Crunchy Shawarma – Restaurant Website

A responsive restaurant website built using **Python, Flask, HTML, and CSS**.

This project provides an online restaurant experience where users can explore the food menu, view available meals and prices, and access table reservation and contact pages.

## 🌟 Features

- **Home Page:** A welcoming landing page featuring popular meals.
- **Food Menu:** Organized food categories with meal names, descriptions, and prices.
- **Table Reservation:** A form for submitting reservation details.
- **Contact Page:** A dedicated page for contact information.
- **Dynamic Pages:** Website pages rendered using Flask and Jinja templates.

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- Jinja2

## 🚀 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/gamilasaeed041-svg/Restaurants-website-.git
```

2. Navigate to the project folder:

```bash
cd Restaurants-website-
```

3. Install Flask:

```bash
pip install Flask
```

4. Run the application:

```bash
python app.py
```

5. Open your browser and visit:

```text
http://127.0.0.1:5000
```
